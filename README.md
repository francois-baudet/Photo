# Photo

Site de galerie photo pour un club de photographes (dépôt, galeries, concours interne).

Cadrage : [conception/besoin.md](conception/besoin.md)

## Structure

- `backend/` : API Node.js + Express
- `frontend/` : interface HTML / CSS / JavaScript (responsive)
- `db/migrations/` : scripts PostgreSQL
- `storage/` : fichiers RAW, aperçus et miniatures (hors git)
- `conception/` : documents de cadrage
